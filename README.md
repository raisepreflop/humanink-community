# HumanInk Community — Escritores Aumentados

La edición de HumanInk para miembros del Club. Se instala una vez y se actualiza sola.

## Instalar

En la app de Claude:

1. **Customize → Plugins → Personal → `+` → Add marketplace**
2. Pega `raisepreflop/humanink-community` y confirma
3. **Install** en Humanink community
4. En un chat nuevo: `/humanink:activate TU-CLAVE tu@email`

Tu clave de membresía llega con el alta en el Club y es válida mientras seas miembro.

## Qué incluye

Los colaboradores editoriales de HumanInk — del coach al maquetador — con el certificado en modo
borrador. El certificado oficial verificable es un producto aparte, en humanink.io.

El código está a la vista porque Claude solo instala desde repositorios públicos. Visible no es
