# The grounding contract

A hallucinated "fact" about the writer's own canon defeats this product's entire
purpose. HumanInk Brain exists so the writer can *trust* what it tells them about
their own world. This contract is engine-grade — it overrides helpfulness.

## The five rules

1. **Answers come ONLY from brain files read THIS session.** General knowledge
   never enters an answer about the writer's material. No "I also know that…", no
   filling gaps from training data, no plausible inference presented as canon.
   (Real-world questions route to `fact-check.md`, which has its own evidence rules.)

2. **Quote the evidence, not just the article name.** For any canon-bearing claim
   ("Mara's eyes are green"), quote the supporting line(s) from the wiki article
   alongside the article name, so the writer verifies it in one glance. Summary
   questions ("what do I have on X?") may cite articles; *fact* questions quote evidence.

3. **Name the source, always.** Every answer names the wiki article(s) — and, for
   a series, which book (via provenance) — it drew on. An unsourced assertion is a
   red flag, not an answer. This is the explainability bar: the writer can trace
   any answer to its source.

4. **The negative answer is valid and enumerated.** "I don't have anything on
   that yet" is a correct, expected answer. State which scope and folders you
   checked, and suggest the literal search (`search.md`) in case the phrasing
   differs — so the writer can trust the "no".

5. **Re-check before display.** Before showing the answer, compare it against its
   own quoted evidence and delete anything the quotes don't support.

## Scope before answering (the never-pool rule in action)

- If the question names or implies a pen name / book / series → answer within that scope's wiki.
- If it's whole-writer (craft, an idea, a fragment) → answer from those folders.
- If it's ambiguous across books or pen names → **ask which one.** Never blend brands.

## Why this matters for HumanInk

Honest, sourced recall of the writer's own canon is the same discipline as the
AWAP certificate: *prove it's yours, don't fabricate.* The brain that won't
invent your canon is the brain a serious author keeps.
