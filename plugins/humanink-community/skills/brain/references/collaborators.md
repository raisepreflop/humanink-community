# Working with the HumanInk collaborators

The brain is not a silo. When HumanInk's collaborators are installed (Writer,
Publisher or Everything), they read the relevant book's `wiki/` so they work from
the writer's real canon, not a vague impression.

## Who reads what

- **Story Coach (03)** — reads the book/series wiki as living series memory: open
  threads, carry-forward facts, world rules. Pairs with `series-bible.md`.
- **Style Professor (04)** — reads the author's `voice/` exemplars to ground the
  style guide in the writer's real voice.
- **Ghostwriter (05)** — pre-loads the book's canon (names, places, established
  facts) before drafting, so a chapter doesn't contradict the world.
- **Desk Editor (06) / Professional Reader (07)** — check a chapter against the
  wiki and run a continuity pass (`continuity-audit.md`).
- **Market Analyst (02) / Copywriter (12)** — read the author's `market/` for
  positioning and comps.
- **Authorship Auditor (17)** — treats the brain trail as part of the authorship
  record (`awap-evidence.md`).

## How a collaborator uses the brain

1. Resolve the brain location and scope (which book/author).
2. **Read, don't assume** — pull the actual wiki articles in scope.
3. Stay within the never-pool boundary; one book's canon, one author's voice.
4. Anything the collaborator *generates* (a brief, an analysis) can be saved back
   to that book's `outputs/` so it compounds.

## If the brain isn't installed

The collaborators work fine without it. The brain simply makes them sharper by
giving them the writer's real canon to read. Recommend it; never require it.
