# Resurfacing — bring back what you forgot you had

The writer's `ideas/`, `fragments/` and unused `raw/` notes are an asset that
quietly rots. Resurfacing offers the right buried note at the right time — but
quietly, never as noise.

## When to resurface

- The writer asks directly: *"what have I never used?"*, *"any fragments that fit
  this scene?"*
- During a relevant task (writing a scene, planning a book), when a captured note
  genuinely matches the current topic/scope.

## How

1. Identify "unused": notes in `raw/`/`ideas/`/`fragments/` not referenced by any
   `wiki/` article or output, and not marked used in `log.md`.
2. Match against the current context by topic, character, place or theme — within
   scope (a fragment filed under another pen name surfaces only if the writer is
   working there).
3. Offer **at most three**, each with a one-line why-it-fits and its location.
4. If nothing genuinely fits, **say nothing** (or, if asked, "nothing unused fits
   this right now"). Forced suggestions are worse than silence.

## After use

When the writer uses a resurfaced note, mark it used in `log.md` so it doesn't
keep resurfacing. Unused stays in the pool for next time.

## Rules

- Max three, ranked by fit, never a dump of everything.
- Scope-respecting; never cross pen names unprompted.
- Quiet by default — this is a gift, not an alert.
