# Daily brief

When the writer opens the brain and asks *"what's new?"* or *"where was I?"*, give
a short, calm orientation — not a dashboard, not a guilt trip.

## What to include (briefly)

1. **Inbox** — how many items waiting to be processed; offer to triage now.
2. **Since last session** — what changed (from `log.md` cursors): notes added,
   wiki updated, answers saved.
3. **Open threads** — from series status / outputs: dangling promises, an unanswered
   question, a planted setup not yet paid off. At most a few, ranked.
4. **One suggested next move** — in the voice of a helpful colleague, clearly
   ignorable. *"Want me to process the 3 inbox notes, or jump back into Book 2?"*

## Rules

- **Short.** A brief is a few lines, not a report. If the writer wants depth, they'll ask.
- **Recommend, never nag.** One suggested move, not a to-do list the writer "must" clear.
- **Scope-aware.** If they're working on a specific book, brief that book; only
  surface whole-writer items if relevant.
- **Honest counts.** "Nothing new since Tuesday" is a fine brief.

The brief reads from logs and outputs — it never invents activity. If a synced
inbox is set up (`schema.md`), phone captures appear here automatically.
